# Sarkari Job Portal

A production‑ready Government Job Information Portal built with Django.

## Features
- Latest Government Jobs, Results, Admit Cards, Answer Keys, Syllabus
- Job search & filtering
- SEO‑friendly URLs and structured data
- Custom admin dashboard
- Mobile‑first responsive design
- PostgreSQL‑ready

## Quick Start (Development)
1. Clone the repository
2. `python -m venv .venv`
3. `.venv\Scripts\Activate.ps1` (Windows)
4. `pip install -r requirements.txt`
5. `python manage.py migrate`
6. `python manage.py createsuperuser`
7. `python manage.py runserver`
